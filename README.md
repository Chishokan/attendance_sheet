# 出席簿アプリ

塾の **Grow顧客管理システム** から書き出した CSV を取り込み、ブラウザ画面上で出欠を入力・集計できる独立 Web アプリです。
ビルド不要・依存パッケージなしで動作し、GitHub Pages などの静的ホスティングにそのまま公開できます。

元の運用（Google スプレッドシート「出席簿作成」「日宇校出席簿」）の仕組みを Web アプリとして再構成しました。
Grow は API を持たないため、生徒情報は **CSV を手動でエクスポートして取り込む** 方式です。

## 主な機能

- **データ取込** … 「会員CSV（生徒マスタ）」と「受講CSV（受講情報）」を貼り付け／ファイル選択で取り込み
- **出欠入力** … 校舎・日付を選ぶと、時間割と受講科目から当日の出席簿を自動生成。生徒ごと・時限ごとに「出席／欠席／遅刻／早退／振替」と理由を入力（自動保存）
- **生徒一覧** … 取り込んだ生徒を校舎・学年・氏名で絞り込み表示
- **集計** … 校舎×月の出席状況（コマ数・出席率など）を一覧／CSV出力
- **設定** … 校舎・科目・時限・時間割マスタの編集、データのバックアップ／復元

## 仕組み（出席簿の自動生成）

1. **受講CSV** の「教室名」＝校舎、科目フラグ＝その生徒の受講科目
2. **時間割マスタ**（校舎×学年×科目×曜日×時限）で、選んだ日付の曜日に開講されるコマを特定
3. 各生徒について「自分の学年・受講科目に該当するコマ」だけを、対応する時限の列に出席欄として表示

時間割・時限・校舎・科目はすべて元スプレッドシートの設定を初期値として登録済みで、「設定」画面から変更できます。

## 使い方（ローカル）

ブラウザは `file://` から ES モジュールを読み込めないため、簡易サーバー経由で開きます（依存ゼロ）。

```bash
node server.js
# → http://localhost:8000 を開く
```

または Python など任意の静的サーバーでも可：

```bash
python3 -m http.server 8000
```

### お試し

`samples/` に**架空データ**のサンプル CSV を同梱しています。
「データ取込」で `samples/会員CSV_sample.csv` と `samples/受講CSV_sample.csv` を読み込み、
「出欠入力」で校舎=日宇校、開講日を選ぶと動作を確認できます。

## CSV の対応列

ヘッダー名で列を判定するため、Grow の標準エクスポート（全列）をそのまま貼り付けても動作します。

- **会員CSV**: `生徒システムコード` / `生徒ID` / `ホーム教室` / `生徒名漢字（苗字・名前）` / `生徒名かな（苗字・名前）` / `学年名` / `保護者携帯メール1` ほか（`削除フラグ` が立つ生徒は除外）
- **受講CSV**: `システムコード` / 科目列 `国語(得点)`〜`英検対策(得点)` / `【教室名】`（＝校舎）/ `【生徒苗字/名前(漢字・かな)】` / `【中学校】` ほか

スプレッドシートのセル範囲をそのままコピー＆ペーストした **タブ区切り** にも対応しています。

## データの保存と個人情報

- 入力した出欠・取り込んだ生徒データは **このブラウザ内（localStorage）にのみ保存** されます。サーバーには送信しません。
- 端末間の共有・引き継ぎ・バックアップは「設定 → バックアップを書き出す／復元」（JSON）を使ってください。
- **実在の生徒氏名・保護者メール・住所等の個人情報はリポジトリにコミットしないでください。** `.gitignore` で実データ CSV を除外しています。

## 公開（GitHub Pages）

このリポジトリをそのまま GitHub Pages（ブランチ／`/` ルート）で公開すれば、`index.html` がそのまま動きます（ビルド不要）。

## ファイル構成

```
index.html              画面の入れ物
server.js               依存ゼロの静的サーバー（ローカル確認用）
src/
  main.js               画面のルーティング
  styles.css            スタイル
  lib/
    csv.js              CSV/タブ区切りパーサー
    grow.js             会員CSV・受講CSV の解析と統合
    schedule.js         時間割→出席簿の生成ロジック
    seed.js             初期マスタ（校舎・科目・時限・時間割）
    store.js            状態管理＋localStorage 永続化
    dom.js              最小 DOM ヘルパー
  views/                各画面（取込・出欠入力・一覧・集計・設定）
samples/                架空データのサンプル CSV
```
